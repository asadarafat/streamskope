# StreamSkope v0.2.0

This release is in development. Continue using the [published download](../start/installation.md)
until the reviewed release assets are available. No live EDA/NSP or installed
upgrade qualification is implied by these notes.

## Independent plugin versions

The desktop now has one Semantic Version, **0.2.0**, shared by the application,
installer and `v0.2.0` release tag. New release identities use normal versions or
prereleases such as `0.2.0-rc.1`; `+build.N` remains historical only.

Plugin API **4** separates each plugin's own version from its requirements. The
initial independent **EDA Capture 0.1.0** and **NSP Capture 0.1.0** packages declare
StreamSkope **>=0.2.0, <0.3.0**, with exact targets EDA **26.8.2** and NSP **26.4.0**.
The catalog filters host compatibility before offering updates, and the plugins
verify the target's version through its API before setup.

Plugin tags publish independently as `plugins/eda/v0.1.0` and
`plugins/nsp/v0.1.0`. Desktop releases contain installers and checksums; plugin
releases supply the plugin bundles/manifests and the NSP workflow download.
The NSP workflow remains inside its verified plugin bundle. The separate EDA
cluster application retains version **26.8.2** and its separate publication process.

## Upgrade and recovery

Installed API 2 and API 3 plugins and their saved profiles remain readable.
Compatible API 4 packages supersede that legacy generation without comparing a
SemVer with the old target-based or revision-based labels. Hot installation,
updates, removal and failed-activation recovery retain their existing lifecycle.

Back up the complete application data before upgrading. API 4 plugins need the
new desktop; an older desktop requires its matching pre-upgrade plugin/data backup.
See [plugin versioning and migration](../plugins/versioning.md) and
[backup and recovery](../guide/recovery.md).

## Qualification

Shared CI and native release packaging must pass for the exact release source.
[Qualification evidence](../guide/qualification.md) tracks the checks and remaining
live/native scenarios. The previous release's results do not qualify this release.
