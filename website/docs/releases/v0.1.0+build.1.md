# StreamSkope v0.1.0+build.1

The first release packages the **0.1.0** desktop application for macOS ARM64,
Windows x64 and Linux x64. The exact release identity is **v0.1.0+build.1**.
These notes describe the intended release contents; availability and checksums
come from the published GitHub release.

## Kafka workbench

Browse topics, inspect and filter messages, export filtered JSON, investigate
consumer lag and run producer/consumer latency probes. Save protected connection
profiles with TLS trust material and OAuth or no-SASL authentication. Manage
topic configuration, Schema Registry and ACLs, and inspect Redpanda transforms
when the corresponding service and permissions are available.

The [compatibility matrix](https://asadarafat.github.io/streamskope/start/compatibility/) describes implemented formats,
authentication and platform boundaries. Kafka is a separate service and is not
bundled with the desktop.

## Connection plugins

Install EDA Capture or NSP Capture from **Preferences → Plugins**. Installation,
updates and removal activate without restarting the desktop. Plugin API **3**
packages declare their minimum desktop release, target version interval and
immutable revision. Both initial plugins require **v0.1.0+build.1**.

- **EDA Capture** targets EDA **26.8.2**. Discover existing Kafka exporters or
  create a temporary broker/exporter through the separate matching EDA cluster
  app. Cleanup removes owned capture resources and preserves the source exporter.
- **NSP Capture** targets NSP **26.4.0**. API credentials allow its bundled helper
  workflow to retrieve Kafka trust material, verify execution cleanup and save a
  reusable profile. Kubernetes credentials are not required. The readable workflow
  and its declared digest are included in the download.

The [plugin guides](https://asadarafat.github.io/streamskope/plugins/) cover prerequisites, setup, call flows,
recovery and lifecycle behavior. Desktop packaging does not publish or replace the
signed EDA cluster app.

## Qualification and limits

Release CI must pass static, unit, integration and documentation checks before
native packaging and draft release assembly. The
[qualification record](https://asadarafat.github.io/streamskope/guide/qualification/) identifies results still to be
recorded. These notes do not claim live cluster or installed native workflow
qualification from automated package checks.

## Download and verify

Once published, obtain installers from the
[v0.1.0+build.1 release](https://github.com/asadarafat/streamskope/releases/tag/v0.1.0%2Bbuild.1).
Desktop packages are unsigned prereleases. Verify the installer against that
release's `SHA256SUMS`, then follow the [installation guide](https://asadarafat.github.io/streamskope/start/installation/).
The official plugin catalog verifies package assets and declared resources before
activation. The unsigned EDA OCI artifact from desktop CI is a development
artifact, separate from a signed EDA App Store publication.
