## Release highlights

Browser documentation now follows installation, opening the vault, connecting,
reading a record, locking and reopening. Everyday use is separate from manual
deployment, offline files and custom networking. Shared release notices identify
StreamSkope rather than describing browser delivery as a desktop release.

This documentation update does not add an upgrade command or change browser
access. Rerunning the installer preserves the installed version and saved data.
