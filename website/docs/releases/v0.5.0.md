# StreamSkope v0.5.0

- Preview exact consumer offset resets, inspect bounded examples and replay
  exposure, then apply to a stopped group with stale-baseline checks and
  per-partition outcome reconciliation. See [offset recovery](https://asadarafat.github.io/streamskope/guide/offset-recovery/).

- Copy a frozen selection to the same topic, another topic or an isolated saved
  profile with explicit transformations, exact destination review, cancellation
  and per-record acknowledgement/uncertainty accounting. See [record replay](https://asadarafat.github.io/streamskope/guide/record-replay/).

- Explain topic READ with prefix/wildcard and DENY semantics, explicit unknown
  broker policy, and reviewed ACL changes that reject stale inputs and retain
  uncertain outcomes. See [access review](https://asadarafat.github.io/streamskope/guide/access-review/).

## Signing and installation

These downloads are unsigned. macOS has no Developer ID signature and is not notarized;
Windows is not Authenticode-signed; Linux is not publisher-signed.
Operating-system warnings are expected. Verify the trusted download against SHA256SUMS
before installing. Checksums verify integrity, not publisher identity or malware safety.
Do not disable operating-system security globally.

[Installation and checksum instructions](https://asadarafat.github.io/streamskope/start/installation/)

## Qualification

[Source-specific qualification report](https://github.com/asadarafat/streamskope/releases/download/v0.5.0/qualification-v0.5.0.json) records the exact source/tree, executed checks and limits; its digest is included in `SHA256SUMS`.

- Shared qualification: 2,310 tests across 272 files; 40 documentation pages and 35 browser routes, including media playback.
- Local 60-second soak: 59,991 records generated and delivered, zero host display drops, 30.56% of one CPU core and 679 MiB peak RSS. All unchanged budgets passed. This measures application ingestion, not real IPC, Kafka fetch or UI interaction latency.
- Four real Kafka recovery tests and one browser scenario passed: reviewed offset reset, faithful same/other/cross-cluster replay and exact ACL access review. No detected Axe violations in the three review dialogs.
- Live EDA 26.8.2: version, capture, lease, real Kafka receipt, unchanged source and idempotent owned-resource cleanup passed.
- Live NSP 26.4.0: workflow, tested/saved profile, idempotent reuse, connection and 176 topics, execution cleanup and hot removal preserving the profile passed. Renderer events excluded credentials and trust material.
- Linux x64, macOS ARM64 and Windows x64 native packages, packaged launch checks and unsigned EDA OCI packaging passed.

The complete local check used one test worker after an earlier four-worker run was interrupted by host memory pressure. No test or budget was relaxed. Installed native plugin upgrades and credential-service recovery were not rehearsed; the live NSP check does not establish Kafka SASL OAuth support. Upstream audit reports 14 affected packages covered by verified pinned mitigations, rather than zero advisories.

## Plugin compatibility

Plugin API remains 4. Source API 4 manifests now permit desktop `>=0.4.0, <0.6.0`; this does not widen already-published packages. Plugin versions and signed EDA cluster-app publication remain separate from this desktop release.
