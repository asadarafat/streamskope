# StreamSkope v0.10.2

## Highlights

Restore readable dark-theme links in expanded plugin availability panels. The intended link palette now takes precedence over the theme default, raising the measured compatibility-link contrast from 4.39:1 to 8.13:1.

Documentation qualification now renders the actual published EDA and NSP availability templates even during preview checks, covering both themes, mobile widths, and normal, hovered and keyboard-focused links.

This patch changes documentation and its qualification checks. Application features, plugin APIs and target compatibility remain unchanged. The [browser quickstart](https://asadarafat.github.io/streamskope/start/containerlab/) provides the one-line latest-version installer without a source build.

## Distribution

A workbench for inspecting Kafka and NATS streams and their supported operations.

## Signing and installation

These downloads are unsigned. macOS has no Developer ID signature and is not notarized;
Windows is not Authenticode-signed; Linux is not publisher-signed.
Operating-system warnings are expected. Verify the trusted download against SHA256SUMS
before installing. Checksums verify integrity, not publisher identity or malware safety.
Do not disable operating-system security globally.

[Installation and checksum instructions](https://asadarafat.github.io/streamskope/start/installation/)
