# NSP Connector 0.1.1

## Unreleased changes

- Rename the display name to **NSP Connector** and the setup action to **Connect via NSP**. The connector retrieves settings for the existing NSP Kafka broker; it does not deploy a capture broker.
- Keep the plugin ID, bundled workflow, package identity, saved profiles and recovery records unchanged. Credential refresh and owned workflow-execution cleanup retain their existing behavior.

## Installation and compatibility

Install from StreamSkope Preferences > Plugins; activation is immediate. Requires plugin API 4.

The primary package remains compatible with existing clients. The separate portable download is publisher-signed and requires a StreamSkope build with signed portable package support; it contains the identical plugin code and resources.

Requires StreamSkope >=0.9.0 and <0.10.0.

Supports NSP 26.4.0 through 26.4.0 (inclusive).

Included resource: nsp-capture.workflow.yaml (SHA256 fbd1ad41aa8fb3bf09adbdadd5ad03ea439edbc6e687b2b66fce2b76db9a920b). The identical resource is available as a separate download.

Source commit: 0acc38c2d5db9c7592cf9adfe835de6d8f0ded93 (tag plugins/nsp/v0.1.1).
