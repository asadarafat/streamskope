# EDA Connector 0.1.1

## Unreleased changes

- Rename the display name to **EDA Connector** and the setup action to **Connect via EDA**. Discovery still offers existing Kafka access and a separate temporary capture; capture start, resume and resource removal remain explicit.
- Keep the plugin ID, package identity, saved profiles and capture recovery records unchanged. Updating applies the new labels without restarting the desktop; normal active-capture cleanup requirements still apply.

## Installation and compatibility

Install from StreamSkope Preferences > Plugins; activation is immediate. Requires plugin API 4.

The primary package remains compatible with existing clients. The separate portable download is publisher-signed and requires a StreamSkope build with signed portable package support; it contains the identical plugin code and resources.

Requires StreamSkope >=0.9.0 and <0.10.0.

Supports EDA 26.8.2 through 26.8.2 (inclusive).

The EDA cluster application is installed separately through the capture workflow.

Source commit: 0acc38c2d5db9c7592cf9adfe835de6d8f0ded93 (tag plugins/eda/v0.1.1).
