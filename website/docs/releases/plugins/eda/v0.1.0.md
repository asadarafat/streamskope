# EDA Capture 0.1.0

## Signed portable installation

For **Install from file**, use `streamskope-eda-portable-v0.1.0.skope-plugin`. The primary `streamskope-eda-v0.1.0.skope-plugin` is the catalog/cache package.

Download the signed portable asset from this plugin release for **Preferences →
Plugins → Install from file** on a supported desktop. It contains the same code
and resources as the primary catalog package and is authenticated by the
publisher key shipped with StreamSkope. Desktop installer releases do not carry
these plugin downloads.

## Upgrade and compatibility

This plugin uses API 4 and independent Semantic Versioning. Install it on a
StreamSkope desktop within the compatibility interval below. The plugin checks
the running EDA version through its API before setup. The EDA cluster application
keeps its own target-aligned version.

Back up application data before upgrading from an API 2 or API 3 plugin. See
[plugin migration](https://asadarafat.github.io/streamskope/plugins/versioning/)
for compatibility and rollback instructions.

## Known limitations

Release CI does not have access to a live EDA cluster. Review the recorded
[qualification evidence](https://asadarafat.github.io/streamskope/guide/qualification/)
before rollout; successful packaging does not establish live capture or cleanup
qualification for the release source.

## Installation and compatibility

Install from StreamSkope Preferences > Plugins; activation is immediate. Requires plugin API 4.

The primary package remains compatible with existing clients. The separate portable download is publisher-signed and requires a StreamSkope build with signed portable package support; it contains the identical plugin code and resources.

Requires StreamSkope >=0.9.0 and <0.10.0.

Supports EDA 26.8.2 through 26.8.2 (inclusive).

The EDA cluster application is installed separately through the capture workflow.

Source commit: 482f361ef52773a298d790400c39fdc931b8cb4e (tag plugins/eda/v0.1.0).

## Recorded acceptance

The actual CI-produced downloads passed shipped-key signature and package/resource-equivalence validation. Native offline installation, repeated import, removal and cached reinstallation passed on 0.9.0 and 0.9.1 compatibility hosts without a restart. The final native live EDA 26.8.2 scenario passed 26 checks with the exact 0.1.0 primary package, including record receipt and owned cleanup.

[Source-specific qualification report](https://github.com/asadarafat/streamskope/releases/download/plugins/eda/v0.1.0/qualification-v0.1.0.json) records evidence digests, source identities, prior failed attempts and scope. Verify it and the downloads against `SHA256SUMS`.

Native acceptance used a Linux ARM64 source Electron shell with stable host-version overrides and scripted file selection. Installed macOS/Windows upgrades and rollback were not rehearsed. EDA reused its installed cluster application; the NSP lab API used certificate verification disabled while Kafka TLS verification remained enabled. Live update checks used a synthetic unsigned newer manifest with unchanged code. Desktop installers remain unsigned.
